# 비서진 (v0)

몰랑이를 모체로 한 개인·가족 비서. 이름은 사용자가 짓는다.
GitHub → Vercel 자동 배포, 상태는 Supabase, 주기 실행은 Supabase pg_cron.

## 구조

```
pyproject.toml      의존성 + Vercel 진입점 지정 (biseo.server:app)
biseo/server.py     API 창구 본체 (Vercel 진입점)
biseo/
  identity.py       정체성 주입 (몰랑이 identity_core 원리)
  absorb.py         사용자 사실 흡수 관문 (몰랑이 molang_store 원리)
  norm.py           정규화·에코 판정 (몰랑이 molang_norm)
  search.py         Brave 검색, 결과 격리 (몰랑이 molang_search)
  notify.py         ntfy 알림, 계정별 주제 (몰랑이 notify)
  privacy.py        번호류 가리기 + 알림 민감어 필터
  actions.py        자율성 등급·승격·강등
  brain.py          대화 한 턴
  tasks.py          과제: 붙잡고 있다가 한 걸음씩 진행
  skills.py         기능: 기본 기능(잠김) + 추가 기능(지울 수 있음)
  apps.py           앱 항목(일정·알림·메모·초안) 만들기·고치기·지우기와 연동
  shortcuts.py      내가 만드는 명령 버튼 (검색·과제 앱)
  tick.py           크론: 사람마다 알림 → 과제 한 걸음 → 확인 알림
  db.py             연결 + Scoped (모든 쿼리에 user_id 자동)
public/index.html   스마트폰식 화면: 홈(오늘 위젯 + 앱 아이콘) → 각 앱
sql/00_schema.sql   테이블·제약·RLS
sql/10_cron.sql     10분마다 tick 호출
sql/20_tasks.sql    과제 테이블 (00 다음에 실행)
sql/30_skills.sql   추가 기능 테이블 (20 다음에 실행)
sql/40_apps.sql     일정·알림 테이블, 앱끼리 연결 (30 다음에 실행)
```

## 설치 순서

1. **Supabase**
   - 새 프로젝트를 만들고 SQL Editor 에서 `sql/00_schema.sql` 실행
   - Authentication > Providers 에서 Email 켜기
     (혼자 쓸 땐 "Confirm email" 을 꺼 두면 가입 즉시 로그인된다)
2. **GitHub** 에 이 폴더를 올린다. `.env` 파일은 올리지 않는다.
3. **Vercel** 에서 그 저장소를 Import
   - Environment Variables 에 `.env.example` 의 값들을 넣는다
   - 배포되면 주소(예: `biseojin.vercel.app`)를 확인
4. **pg_cron**
   - Supabase > Database > Extensions 에서 `pg_cron`, `pg_net` 켜기
   - `sql/10_cron.sql` 의 `<YOUR_APP>`, `<CRON_SECRET>` 을 바꿔서 실행
   - `sql/20_tasks.sql`, `sql/30_skills.sql`, `sql/40_apps.sql` 차례로 실행
5. 폰에 **ntfy** 앱을 깔고, 앱의 설정 화면에 나오는 주제를 구독

## 자율성 등급

| 등급 | 뜻 | 처리 | 지금 있는 종류 |
|---|---|---|---|
| 1 | 보기·찾기 | 바로 실행 | 검색 |
| 2 | 제안·초안 | 만들어서 보여 줌 | 초안 |
| 3 | 나에게만, 되돌릴 수 있음 | 처음엔 묻고, 수정 없이 5번 승인되면 묻지 않음 | 메모, 알림 예약 |
| 4 | 남에게 닿음, 되돌릴 수 없음 | 언제나 묻는다 (승격 없음) | 메시지 보내기 (아직 꺼져 있음) |

- 자동 실행한 일을 되돌리면 그 종류는 다시 묻는 단계로 내려간다.
- 바깥(메일·문자)에서 들어온 내용이 계기면 무조건 4등급. DB 제약으로도 막혀 있다.
- 승격 기록은 계정마다 따로 쌓인다.

## 몰랑이에서 지킨 것, 바꾼 것

**지킨 것**
- 신뢰 구조를 DB 제약으로 강제: 사용자 본인 말만 사실이 되고, 사람 승인 없이 human 신뢰는 없다
- 검색 결과는 답변 문맥으로만 쓰고 기억으로 흡수하지 않는다
- 비서 자기 말이 사실로 굳는 것(assistant echo)을 검역소로 보낸다
- 먼저 말을 거는 것은 규칙이 정한다. 계기가 없으면 아무 말도 안 한다

**바꾼 것**
- 이름과 목적: 몰랑이가 아니라 사용자가 이름 짓는 비서, 목적은 바깥(사용자의 일)
- 업무 기억(`task_memory`)과 사용자 사실(`facts`)을 테이블부터 분리
- 모든 행에 `user_id` + RLS. 지금 한 명이어도 가족 계정을 붙일 수 있는 바닥

## 과제 (에이전트 부분)

대화에서 여러 걸음이 필요한 일을 부탁하면 비서가 과제로 맡는다.
pg_cron 이 깨울 때마다 사람당 과제 하나를 한 걸음 진행한다.

- 한 걸음 = 판단 → 행동 0~1개(등급 규칙 그대로) → 기록
- 확인이 필요한 행동이 나오면 과제는 멈추고, 결정하면 이어서 간다
- 사용자만 아는 정보가 필요하면 묻고 멈춘다. 대화로 답해도, 화면에서 답해도 된다
- 같은 행동을 반복하려 하면 멈추고 묻는다. 걸음 한도(기본 12)에 닿으면 멈춘다
- 과제 기록은 업무 기억이다. 사용자 사실로 흡수되지 않는다
- 화면의 "지금 한 걸음"으로 크론을 기다리지 않고 진행할 수 있다

## 화면: 홈과 앱

홈에는 오늘 위젯(오늘 일정, 다음 알림, 확인할 일)과 앱 아이콘이 있다.
채팅에서 한 말은 각 앱의 항목으로 생기고, 앱에서 보고·고치고·지울 수 있다.

| 앱 | 하는 일 |
|---|---|
| 채팅 | 부탁하기. 만들어진 항목으로 바로 가는 버튼이 붙는다 |
| 일정 | 날짜별 목록, 편집, 붙은 알림·메모 관리 |
| 메모 | 목록, 편집, 일정에 붙이기 |
| 알림 | 다가올·지난 알림, 편집 |
| 맡은 일 | 과제 진행·답하기·그만두기 |
| 초안 | 보기, 고치기, 복사 |
| 기능 | 기본·추가 기능, 실행·지우기 |
| 확인함 | 하기·하지 않기, 되돌리기 |
| 설정 | 이름, 알림 주제, 로그아웃 |

연동 규칙
- 일정 시각·이름을 바꾸면 "몇 분 전"으로 붙은 알림이 따라 움직인다
- 일정을 지우면 붙은 알림도 지워지고, 붙은 메모는 남는다
- 알림 시각을 직접 바꾸면 그 알림은 일정과 따로 움직인다
- 알림은 가져가기(claim) 방식이라 틱이 겹쳐도 한 번만 간다

## 기능

- 기본 기능(검색·메모·알림·초안·과제)은 코드에 있고 지울 수 없다.
- 추가 기능은 "지시문 + 쓸 수 있는 기본 도구 목록"이다. 코드가 아니다.
  - 사용자가 부탁하거나, 비서가 반복되는 부탁을 알아채고 제안하면 확인함에 올라온다 (tier 3)
  - 승인하면 사이드바에 생기고, 지우기·되돌리기로 없앨 수 있다
  - 실행하면 그 지시문을 품은 과제가 생기고, 기능이 허락한 도구만 쓴다
  - DB 제약(skill_tools_ok)이 기본 도구 밖의 도구를 막는다.
    그래서 기능이 늘어도 비서가 할 수 있는 행동의 범위는 넓어지지 않는다

## Vercel 배포 방식

Vercel 의 FastAPI 프로젝트 방식(zero-config)을 쓴다. `vercel.json` 이 필요 없다.
- `pyproject.toml` 이 가리키는 `biseo/server.py` 의 `app` 을 Vercel 이 하나의 함수로 띄운다
- `public/` 의 파일(index.html, 아이콘, manifest)은 Vercel 이 직접 내준다
- 함수는 원래 주소(`/api/config` 등)를 그대로 받는다

## 알아 둘 점

- Vercel Hobby 는 비상업적 개인 용도 전용이다.
- 브라우저는 Supabase 에 직접 쿼리하지 않고 API 만 부른다. 다만 로그인 토큰으로
  자기 행은 직접 고칠 수 있다 (RLS 는 남의 행만 막는다). 가족 규모에서는 괜찮지만,
  외부 사용자를 받게 되면 쓰기는 서버 전용 함수로 옮길 것.
